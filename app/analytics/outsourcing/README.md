# Outsourcing Analytics

A comprehensive analytics dashboard for monitoring outsourced medical services, facility performance, and financial metrics.

## Features

### 📊 Multiple Analytics Types
- **Daily Amounts (Last 30 Days)**: Track daily outsourcing expenditures
- **Monthly Amounts (Last 12 Months)**: Monthly trends and patterns
- **Yearly Summary by Facility**: Annual performance by outsourcing facility
- **Top 20 Facilities**: Ranking of highest-performing facilities
- **Hourly Patterns**: Service distribution throughout the day
- **Top Facility per Month**: Monthly facility performance leaders
- **Summary Dashboard**: Overall outsourcing metrics
- **Current Year Analytics**: Year-to-date performance data

### 📈 Visualization Options
- **Bar Charts**: Traditional bar visualization
- **Pie Charts**: Proportional distribution views
- **Line Charts**: Trend analysis over time
- **Area Charts**: Cumulative performance visualization

### 🎯 Key Metrics
- Total outsourced amounts
- Service counts by facility
- Average cost per service
- Facility performance rankings
- Time-based patterns and trends

## Usage

1. **Select Analytics Type**: Choose from dropdown menu
2. **Choose Visualization**: Bar, Pie, Line, or Area chart
3. **Set Date Range**: Customize start and end dates
4. **Load Data**: Click Load button to fetch analytics
5. **Reset**: Return to default date range

## Data Sources

Connects to `/api/financial-analytics` endpoint with various analytics keys for comprehensive outsourcing insights.

## Color Scheme

Uses OKLCH color system for accessibility and consistency with other analytics components.
