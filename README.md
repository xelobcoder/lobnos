lobnos

A laboratory information storage system for the [Lobnos](https://lobnos.org) project.


Features

1. Patient or client registration portal system


2. Patient or client data management system


3. Patient or client data visualization system


4. Patient or client data analysis system


5. Patient or client data reporting system


6. test input system 


7. Inventory management system


8. Sugar management system
