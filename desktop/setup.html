Local installation setup

Authorize installation, then supply temporary local MySQL 8 administrator access. PLS creates its databases and a dedicated application account automatically. There is no universal MySQL administrator password.

Saved application credentials are encrypted for this OS account. The installation password and MySQL administrator password are not saved. Signed device/facility activation is still required. Existing databases not owned by this installation will never be overwritten.

Temporary local MySQL administrator access

Database names, application account, organization identity and security keys are generated internally. Do not delete saved provisioning state after a failure; retry with the same organization and local endpoint.
