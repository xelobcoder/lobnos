Local installation setup

Authorize this local installation. PLS creates its database, a default organization, and a default administrator login automatically — change them from within the application after first login.

Saved application credentials are encrypted for this OS account. The installation password is not saved. Signed device/facility activation is still required. Existing databases not owned by this installation will never be overwritten.

Database name, organization name, administrator login, and local connection details are fixed/defaulted internally. Do not delete saved provisioning state after a failure; retry with the same installation password.
